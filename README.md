# РРО АЗС — оновлення програми

Тут викладаються готові збірки касової програми для АЗС з ЕККР «Марія-303А1» (Windows 10/11, один файл `RroAzs.exe`, нічого додатково встановлювати не треба). Код програми тут не публікується.

Остання версія — у розділі **[Releases](../../releases/latest)**: файл `RroAzs-<версія>.exe` і опис змін.

## Встановлення вручну

1. Закрийте програму на касі.
2. Скачайте `RroAzs-<версія>.exe`, перейменуйте на `RroAzs.exe` і замініть ним файл у папці програми (рекомендовано `C:\RroAzs\RroAzs.exe`).
3. Запустіть програму. Налаштування, користувачі та журнали зберігаються окремо від exe і не губляться.

Якщо Windows попередить «Система захистила ваш комп'ютер» — натисніть «Докладніше» → «Виконати все одно»: збірка не має комерційного сертифіката.

## Перевірка файлу

У кожному релізі вказано SHA-256 файлу. Перевірити скачаний файл можна командою:

```
certutil -hashfile RroAzs.exe SHA256
```

Рядок має збігатися з указаним у релізі.
